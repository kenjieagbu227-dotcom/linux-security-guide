# 05 — Linux Security Guide

**Linux security fundamentals, hardening, permissions, services, and monitoring.**

This repository teaches practical Linux security practices for system administrators and security learners.

---

## About

Linux powers a large portion of servers and infrastructure. Securing Linux systems is a critical skill in cybersecurity.

---

## Learning Objectives

- Understand Linux users and groups
- Learn file and directory permissions
- Understand processes and services
- Learn SSH security
- Understand privilege management
- Learn basic system hardening
- Understand logs and security monitoring
- Learn secure software and package management

---

## Topics Covered

| Topic | Description |
|-------|-------------|
| Users & Groups | Account management |
| File Permissions | chmod, ownership, special bits |
| Sudo | Privilege escalation control |
| SSH | Secure remote access |
| Processes & Services | Managing running software |
| Firewall | Host-based firewall rules |
| Logs | Authentication and system logs |
| Package Security | Safe updates and software sources |
| System Hardening | Reducing attack surface |

---

## Defensive Fixes

- Disable unnecessary services
- Use least-privilege accounts
- Secure SSH configuration (prefer key-based auth)
- Restrict sudo privileges
- Keep packages updated
- Configure firewall rules
- Monitor authentication logs
- Remove unnecessary software
- Apply appropriate file permissions
